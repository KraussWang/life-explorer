# P0 MVP 验收记录

日期：2026-10-17。环境：Windows / 本机 Microsoft Edge 无头浏览器，Playwright，生产预览 `127.0.0.1:4173`。截图分辨率 1440×900、1280×720。

## 结果

- 生产构建成功。
- 4 项独立状态测试通过。
- 45 项完整流程浏览器断言通过，未捕获运行异常或控制台错误。
- 7 项异常恢复浏览器检查通过。
- 独立审查 agent 初审发现 1 项异常存档校验问题，修复后复审通过，无待处理的确定性发现。

## M1

保留原海洋的海床、热液喷流与水体效果；实际单细胞 GLB 可随 WASD 游动。通过真实键盘采集 3 个营养点，验证未满足条件时 E 无效、满足后只提供机会。暂停期间位置不变。

## M2

真实游动完成鞭毛阶段资源收集、冷流触发、同类聚集、多细胞复杂食物和特化资源采集。验证极寒不是自动计时触发、极寒中刷新可恢复、进入多细胞后寒潮结束且更新为 S02。每次过场锁定输入，结束后模型与物种一致。蠕虫使用分节运动占位模型。

## M3

从蠕虫逐一选择双壳贝、海蛞蝓、原始鱼型，每条路线均进入解锁终点；图鉴加载对应 3D 模型，执行旋转、缩放、前后切换；返回分叉不丢失图鉴，累计 7/7。刷新恢复分叉点与全部发现。验证画质切换、最低海床高度、重启确认取消、重启后保留图鉴。

## 恢复与资产

损坏 JSON、未来版本、资源记录矛盾均显示存档错误并允许新游戏。禁用 localStorage 仍可移动并提示仅当前会话。模拟鱼模型 HTTP 503，验证保持蠕虫与原进度；解除错误后重试成功。未解锁图鉴不提供模型预览。

鱼运行副本为 10 万三角面 / 7.0 MB，扇贝运行副本约 7.4 MB，原始输入保留。图鉴打开时停止连续渲染海洋。本机 1280×720、流畅档鱼场景样本为 60 FPS；这是单机样本，非跨设备性能保证。最终对鱼型 / 海蛞蝓做了 +Z 源模型到 -Z 移动前向的统一，并重新构建、复跑异常恢复与鱼模型展示检查。

## 交付边界

第二环境使用原海床加生态层与光照变体；蠕虫是明确标注的程序化占位；鞭毛 / 鱼使用顶点形变而非骨骼。目标平台为桌面键鼠，未实现移动摇杆或 P1 / P2 后续路线。
