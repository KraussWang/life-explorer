# 生物图鉴

游戏内点击「生命图鉴」或在探索时按 Tab 打开；Esc 返回。开发预览：`npm run dev -- --port 4173`。

## 页面与操作

以 `视觉效果/概念图/生物图鉴.png` 为布局参考：全屏深青海洋底色、品牌横幅、左侧分类与收集进度、中间五列卡片、右侧标本与信息、底部稀有度图例。青色为筛选高亮，金色描边为当前选中，绿 / 蓝 / 金色菱形区分普通、稀有、关键节点。小屏改为可滚动的上下布局。

左侧包含演化生物、环境植物、海洋生物、收藏统计；顶部提供类别与全部状态 / 已解锁 / 未解锁的组合筛选。详情只有一个「查看模型」动作；锁定条目展示剪影与解锁提示，无法查看模型。

## 数据结构与收录范围

`src/catalog.js` 独立于可玩角色的 `src/species.json`。每条记录包含 `id/name/latin/category/rarity/model/trait/habitat/description/era/unlock/image`；`variants` 可选，用于同一生物的带骨骼模型。`image` 包含来源、视角标签、卡片主视角、各视角图片地址，以及源图像素裁剪矩形。

共 25 个条目：7 个可玩演化形态、6 个当前场景可观察对象、12 个后续生态章节档案。全部条目连接真实模型，不新增或修改现有演化分支。后续档案明确提示等待相应生态章节，没有虚构「已解锁」状态。

资产库生物覆盖：单细胞、鞭毛细胞、多细胞、蠕虫、扇贝、海蛞蝓、无鱼鳍鱼、肺鱼、两栖动物、早期脊索动物、有鳍鱼、鲸、霸王龙、象、扇形海草、灌木、形似灌木、树、管状珊瑚、团块珊瑚。珊瑚归入海洋动物。另加入游戏现有丝状藻、叶状海藻、水草、浅海藻和海星。PBR / shaded / LOD 为同一生物的资源版本，不重复计数；骨骼包中的鱼、扇贝、有鳍鱼作为查看器版本，鲸作为独立条目。石头、热液喷口、非生物营养絮团不作为生物条目。

## 图片规则

1. 不从 UI 参考图提取生物作为卡片。参考图只裁出顶部海洋装饰与左下角化石装饰。
2. 对已确认与模型对应的 8 张源图逐视角裁剪：单细胞、鞭毛、多细胞、蠕虫、双壳贝、海蛞蝓、原始鱼类（早期脊索动物资产）、腔棘鱼（有鳍鱼资产）。源文件名虽常写「三视图」，实际有四个视角时按四视图处理。
3. 单细胞源图只有正面 / 侧面 / 背面，明确展示三视图，不复制一张伪造第四视角。保留源图实际方向名称，如扇贝卡片选用「背面」的扇形外壳。
4. 像素裁剪框与来源保存在 `public/atlas/images.json`。裁剪移除边缘白底与英文标注，保留原始生物形态。`scripts/prepare-atlas-assets.py --images-only` 可重建。
5. 没有对应多视角源图的资产，使用真实 GLB 渲染四向图，界面标明「原始模型 · 四向观察」。不使用其他生物的图片替代。`scripts/render-atlas-images.mjs` 为开发构建工具，配合开发服务器和 `review/atlas-render.html` 使用。

## 模型与集成

GLTFLoader 点击后按需加载；独立 WebGLRenderer + OrbitControls 支持旋转、滚轮 / 双指缩放、重置视角。模型以真实包围盒归一化，AnimationMixer 播放可用骨骼动画。加载失败可重试；关闭时取消过期加载结果、释放模型几何 / 材质 / 纹理、OrbitControls、渲染器及 WebGL context。查看器不会替换游戏角色或占用主场景相机。

新增模型来自 `视觉效果/3D资产`，OBJ 以原始 diffuse 贴图导入，输出独立 GLB 副本，目标约 60k 面、1024px 贴图，保留骨骼动画。现有游戏模型继续复用，蠕虫图鉴使用真实 `蠕虫.glb`，不改动游戏原有程序蠕虫。转换清单见 `public/atlas/model-provenance.json`；源资产保持原样。

## 解锁与保存

- 演化条目读取已有 `state.unlocked`，到达形态后解锁。
- 植物与海星读取新增 `state.discoveries`。原始海洋使用实际藻类放置坐标及当前生长值；浅海使用场景 manifest 的真实实例坐标。玩家进入约 3.5–4 米观察范围后发现并立即保存。暂停、图鉴、过渡期间不触发探索。
- 沿用 `life-explorer.p0.v1` 存档键；旧存档无 discoveries 时迁移为空数组。校验 ID、去重；重新开始和返回分叉保留两类收集记录。
- 图鉴与查看器使用原有原生 dialog 暂停机制，清除运动按键；关闭后恢复场景控制。没有修改场景、碰撞或演化条件。

## 验证

`npm test` 覆盖已有状态逻辑及新增存档迁移、实例接近判定、所有图鉴资源路径。`npm run test:atlas` 检查分类 / 锁定 / 真实模型 / 骨骼版本 / 双层 Esc / 暂停恢复 / 重新载入，并输出 1672×941、1280×720、390×844 截图。`npm run test:e2e` 走完原有演化流程与三条分支。

图鉴验收脚本使用隔离浏览器存档夹具展示多条已发现记录；产品没有开发者解锁入口。验收截图不是用户实际存档进度。
