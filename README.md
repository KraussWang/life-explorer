# 生命探索者 · Life Explorer

一款基于 Three.js 的桌面浏览器演化探索游戏。从原始海洋中的单细胞出发，寻找营养、适应环境，并探索通往鱼类、陆地与海洋哺乳动物的不同生命支系。

游戏采用可交互的 3D 海洋、真实模型与本地存档。无需 API key、云服务或外部 CDN。

## 开始使用

需要 Node.js 和 npm。推荐使用桌面版 Edge 或 Chrome，并通过本地 HTTP 服务器运行（不要直接双击 HTML 文件）。

```powershell
npm ci
npm run dev
```

在浏览器打开 <http://127.0.0.1:5173/>。

构建并预览生产版本：

```powershell
npm run build
npm run preview -- --port 4173
```

生产预览地址为 <http://127.0.0.1:4173/>。Windows 用户也可运行 `./start-preview.ps1` 启动本地预览。

## 游戏内容

- **原始海洋**：从原始单细胞开始，收集有机絮团，经历鞭毛细胞、多细胞集合体和蠕虫状祖先等阶段。
- **演化分支**：在条件满足后选择双壳贝、海蛞蝓或原始鱼型等探索路线；鱼型旅程可继续进入鱼类、四足动物、陆地动物、鸟类和海洋哺乳动物章节。
- **生态探索**：探索热液喷口、海床、早期丝状藻类生态与史前浅海栖息地，并在后续章节体验森林等环境。
- **生命图鉴**：发现生物与植物，查看分类、演化信息及可旋转缩放的 3D 模型。图鉴进度会保存在本地。
- **自动存档**：探索进度保存在当前浏览器的 `localStorage` 中；不同浏览器和不同本地端口的存档彼此独立。

## 操作

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 移动 | W / A / S / D 或方向键 |
| 上浮 / 下潜 | Space / Q（部分章节使用 Ctrl 或不适用） |
| 加速 | 左 Shift |
| 与目标互动、取食或确认当前提示 | E |
| 对准下一个探索目标 | R |
| 打开 / 关闭生命图鉴 | Tab |
| 暂停或关闭当前面板 | Esc |
| 环顾 / 缩放 | 拖动鼠标 / 滚轮 |

部分章节会根据生物形态调整互动方式；进入游戏后可按屏幕提示操作。演化选择表现的是跨越许多世代的种群变化，并非个体即时变成另一物种。

## 开发命令

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动 Vite 开发服务器 |
| `npm run build` | 构建网站到 `dist/` |
| `npm run preview -- --port 4173` | 预览生产构建 |
| `npm test` | 运行 Node.js 单元测试 |
| `npm run test:e2e` | 运行主流程浏览器测试 |
| `npm run test:atlas` | 运行生命图鉴浏览器测试 |
| `npm run test:chapters` | 运行后续章节浏览器测试 |
| `npm run test:algae` | 检查藻类生态预览 |

浏览器测试需要相应的本地预览服务器；部分脚本使用本机 Microsoft Edge。执行前请查看具体脚本中的地址和环境要求。

## 预览页面

- `index.html`：主游戏入口，也是推荐的完整旅程入口。
- `chapters.html`：鱼型至陆地章节的独立预览入口。
- `algae-preview.html`：早期藻类生态的独立预览，可调整生长阶段和观察机位，不读写游戏存档。

## 项目结构

```text
index.html                 主游戏页面
chapters.html              后续章节独立预览
algae-preview.html         藻类生态预览
main.js                    主游戏入口与集成
src/                       游戏状态、场景、图鉴、藻类及章节模块
public/                    浏览器运行所需的模型、图片、音频与场景资源
assets/source/             可编辑的 Blender 源资产
scripts/                   构建、资源检查与浏览器测试脚本
README-*.md                场景、图鉴、藻类等专题说明
```

Blender 仅在重新生成部分 3D 源资产时需要；运行游戏和构建网页无需 Blender。`public/` 中的 GLB 等资源已用于运行时加载。
